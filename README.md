# ТИШЕ — йога в своём ритме

Первый вариант сайта преподавателя йоги. Рабочее название, все цены, занятия и события — демонстрационные. Данные реального преподавателя не выдуманы. Фотографии созданы ИИ.

**Посмотреть:** https://tonykurman.github.io/tishe-yoga/

## Что работает

- Адаптивная главная, подход, преподаватель, цены, события, журнал, галерея, FAQ, контакты.
- Фильтры расписания по формату, направлению и уровню.
- Три статьи, программы двух примерных событий, просмотр фотографий.
- Доступные с клавиатуры диалоги и демонстрация записи с проверкой полей.
- Страница об обработке данных текущего макета.
- Автоматическая публикация GitHub Pages после изменений в `main`.

## Что пока является заглушкой

Настоящие имя и фото преподавателя, биография, сертификаты, отзывы, адрес, контакты, реквизиты, даты событий и цены. Формы **не отправляют и не сохраняют данные**, оплата не подключена. Нет действующей CMS, календарной синхронизации, счётчиков аналитики или видеозаписей. Все эти подключения требуют реальных аккаунтов и согласования данных владельца.

## Как редактировать

- `dist/content.js` — расписание и полные тексты статей.
- `dist/index.html` — тексты разделов, карточки цен, события и контакты.
- `dist/style.css` — цвета и оформление.
- `dist/assets/` — изображения и векторный логотип.

В GitHub откройте файл → карандаш → внесите изменения → Commit changes. После успешного workflow сайт обновится. Это редактирование исходников, не полноценная CMS.

## Локально

Нужен Python 3. Запуск: `python3 -m http.server 4173 --directory dist`. Открыть http://localhost:4173.

Проверка JS: `npm run check`. Сборка и зависимости не требуются.

## Перед рабочим запуском

1. Заменить демонстрационные данные и ИИ-фото преподавателя на проверенные.
2. Подключить настоящую систему записи, уведомления, оплату и управление контентом.
3. Подготовить документы и механизм обработки персональных данных для реальных процессов.
4. Подключить календарь и аналитику под аккаунтами владельца.
5. Выбрать окончательное название и домен; проверить права и доступность.

Полные заметки по материалам: `docs/HANDOFF.md`. Происхождение изображений: `docs/IMAGE-PROMPTS.md`.
