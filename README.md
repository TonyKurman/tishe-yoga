# Глубже — йога с Викторией Носковой

**[Открыть сайт](https://tonykurman.github.io/tishe-yoga/)** · **[Инструкция клиенту: REG.RU → GitHub](docs/REG-RU-GITHUB.md)**

Сайт преподавателя йоги с реальными фотографиями, спокойной анимацией и типографикой в духе редакционного дизайна. Обновлён 27 ноября 2026 года.

## Что работает

- Адаптивная главная, знакомство с преподавателем, расписание, цены, события, журнал, галерея, FAQ и контакты.
- Фильтры расписания по формату, направлению и уровню.
- 16 фотографий: категории, просмотр всей серии, полноразмерные кадры и перелистывание.
- Плавный курсор с кольцом, анимации заголовка/прокрутки, орбиты и живая композиция с кругами.
- Общая и отдельная пауза анимаций, системное уменьшение движения; на сенсорных устройствах нет искусственного курсора.
- Демонстрационная запись с валидацией. Три статьи и программы примерных событий.
- Автоматическая публикация GitHub Pages после push в `main`.

## Данные для следующего этапа

Опубликованы биография Виктории, четыре квалификации, направления практики и ссылки на её Telegram и Instagram. Для следующего этапа нужны подтверждённый телефон, адрес зала, реквизиты, цены, расписание и даты событий. Реальная запись, оплата, CMS, календарь и аналитика не подключены. Демонстрационные формы не отправляют и не сохраняют данные.

## Редактирование

- `dist/content.js` — расписание, статьи и состав фотогалереи.
- `dist/index.html` — тексты разделов, цены, события и контакты.
- `dist/style.css` — оформление и CSS-анимации.
- `dist/motion.js` — курсор, появление блоков и управление анимацией.
- `dist/app.js` — фильтры, формы, галерея и диалоги.
- `dist/assets/photos/` — выбранные фото без EXIF, в двух размерах.
- `dist/assets/fonts/` — локальные шрифты и лицензии.

В GitHub можно открыть файл, нажать карандаш и сохранить изменения коммитом. Это редактирование кода, не визуальная CMS.

## Проверка и локальный запуск

`npm run check` — синтаксис всех JS-файлов.  
`python3 -m http.server 4173 --directory dist` — локальный просмотр на http://localhost:4173.

Сборка и установка зависимостей для сайта не требуются. Pillow нужен только для скриптов подготовки фотографий. Оригиналы в `source-photos/` игнорируются Git.

История изменений и происхождение материалов: [обновление 25.11](docs/UPDATE-2026-11-25.md), [карта фотографий](docs/photo-manifest.json). Документация первоначальных ИИ-картинок сохранена в `docs/IMAGE-PROMPTS.md`; новая версия их не использует.
